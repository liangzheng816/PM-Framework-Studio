## Project Overview

**Framework Studio** — a premium web product that teaches product management frameworks through a beautiful, interactive learning experience. The repository contains 100 PM framework markdown files as source content, a comprehensive PRD, and a fully built Next.js web application.

## Repository Structure

- `PM_Frameworks/` — 100 source markdown framework files (`001_*.md` through `100_*.md`) with YAML frontmatter. Each follows an 11-section template.
- `PM_Frameworks/framework_manifest.json` — Index of all 100 frameworks with order, group, filename, confidence.
- `PRD/pmframe_inspired_prd.md` — Full product specification (27 sections).
- `PRD/pm_frameworks_research_summary.md` — Research workbook with bilingual (EN/CN) framework summaries.
- `framework-studio/` — The Next.js web application (all dev commands run from here).

## Build & Dev Commands

All commands run from `framework-studio/`:

```bash
npm run dev          # Start dev server (Turbopack, http://localhost:3000)
npm run build        # Production build (generates 120 static pages)
npm run start        # Serve production build
npm run lint         # ESLint
npx tsx scripts/migrate-content.ts        # Re-run content migration (PM_Frameworks/*.md → content/en/frameworks/*.mdx)
npx tsx scripts/generate-map-positions.ts # Regenerate map positions for SVG scatter map
```

## Tech Stack

Next.js 16 (App Router) + TypeScript (strict) + Tailwind CSS v4 + Framer Motion + MDX filesystem content + Fuse.js client-side search + Plausible analytics + Vercel deployment

**Next.js 16 note**: `params` and `searchParams` are async Promises — always `await params` in page components.

## App Architecture

### Pages (`framework-studio/app/`)
- `/` — Homepage: hero with gradient mesh + Framer Motion entrance, category ribbons, featured frameworks, trust section
- `/explore` — Browse + search: Fuse.js fuzzy search, category filters, grid/list toggle
- `/framework/[slug]` — Deep-dive: parsed MD sections, sticky sidebar nav, related frameworks, collapsible source notes, mobile action bar, save button, JSON-LD schema
- `/category/[slug]` — Category landing: hero + framework grid
- `/map` — Interactive SVG scatter map (x: stage, y: qual/quant), category filters, hover tooltips, mobile grouped list fallback
- `/compare` — Side-by-side comparison: select 2–4 frameworks, 9-attribute table, differences-only toggle
- `/finder` — Guided wizard: 4 questions → ranked recommendations with staggered animation
- `/collections` — Saved frameworks (localStorage): heart icon on cards, custom event sync
- `/about` — Methodology and confidence label explanations
- `/sitemap.xml`, `/robots.txt` — Auto-generated

### Key Modules
- `lib/frameworks.ts` — Content loader: reads MDX from disk, parses frontmatter, caches in memory. Exports: `getAllFrameworks()`, `getFrameworkBySlug()`, `getFrameworksByCategory()`, `getRelatedFrameworks()`, `getFeaturedFrameworks()`, `getCategoriesWithCounts()`
- `lib/types.ts` — Core interfaces: `Framework`, `Category`, `Collection`, `CategorySlug`, `SearchableFramework`
- `lib/collections.ts` — localStorage CRUD for saved frameworks
- `lib/category-colors.ts` — Tailwind-safe category color class mappings
- `lib/motion.ts` — Shared Framer Motion animation variants
- `components/search/command-palette.tsx` — Global Cmd+K / `/` search overlay with ARIA combobox
- `components/deep-dive/source-notes.tsx` — Collapsible source & lineage panel with Framer Motion
- `components/deep-dive/mobile-action-bar.tsx` — Sticky bottom bar (save, compare, share)
- `components/framework-map/interactive-map.tsx` — SVG scatter with category-colored nodes + Framer Motion tooltips

### Content Pipeline
- `content/en/frameworks/` — 100 migrated MDX files with enriched frontmatter (generated by `scripts/migrate-content.ts` from `PM_Frameworks/`)
- `data/search-index.json` — Pre-computed Fuse.js search index (generated alongside migration)
- `data/map-positions.json` — Editorial x/y coordinates for framework map (generated by `scripts/generate-map-positions.ts`)
- `data/categories.ts` — Category metadata, descriptions, ordering

### Design System
- `app/globals.css` — Design tokens as CSS custom properties + Tailwind `@theme inline` integration
- Theme: Midnight editorial dark (default) + light mode via `[data-theme="light"]`
- Fonts: Instrument Serif (headings), Inter (body), JetBrains Mono (code)
- Motion: 120–240ms spring-based, prefers-reduced-motion respected
- Accessibility: skip nav, focus-visible outlines, ARIA on command palette, keyboard navigation

## Design Constraints (PRD §25)

- Avoid generic template aesthetics, crowded dashboards, loud gradients, excessive neon
- Prioritize readability on long-form pages
- Never ship placeholder lorem ipsum — use real framework content
- Dark mode must feel luxurious, not gamer-style
- WCAG 2.2 AA accessibility target
- Lighthouse performance > 90, LCP < 2.5s on mobile
