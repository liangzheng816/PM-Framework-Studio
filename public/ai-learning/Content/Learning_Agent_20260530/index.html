How to use this library

Suggested flow

  • Read a guide section — each guide has a sticky topic-nav at the top for quick jumps. Content is presented as auto-numbered slide panels.
  • Quiz yourself immediately after — use the per-guide quiz at the bottom of each guide, or jump straight to the Full Quiz for all 26 questions at once.
  • Drill flashcards — tap any card to flip it. The Flashcard Deck has all 45 cards with guide filtering and shuffle for spaced repetition.
  • Print to PDF from any guide for an offline reference sheet — the slide-panel layouts are print-friendly.
