Quick Steps — buttons that run AI for your team

A column of buttons in any SharePoint list. Each button is a saved prompt. Users click; SharePoint AI runs. No one has to know how the AI pane works.

A Quick Step is a one-click AI action

A Quick Step is a button that sits directly inside a SharePoint list or library row. Click it and the AI in SharePoint pane opens with a prompt already populated and ready to run against that item. The user does not have to type, choose a skill, or even know that an AI exists.

Quick Steps put AI in front of users as a button, not a chat box. Click "Generate socials" — the work happens.

The example in the demo is a "Generate Socials" button on a social media library. One click triggers an AI run that produces the social copy for that item. The user never opens a prompt window — they just click the button next to the file.

"Quick Steps need Power Automate or a custom workflow." They don't. A Quick Step is a built-in SharePoint feature; the AI behavior is configured inline.

The Actions column — where Quick Steps live

You add a Quick Step by adding a column of type Quick Step (the demo calls it "actions"). Each row of the library then shows whichever Quick Steps you have defined as a row of clickable buttons. Every item in the library inherits the same buttons by default.

One Quick Step column can hold many buttons. The column is the container; each button is a saved action.

This means a single library can offer multiple Quick Steps side by side — Summarize, Standardize Filename, Generate Socials, Convert to Markdown — without cluttering other columns. Users see the actions exactly where the file lives.

"I need a separate column per button." No — one Quick Step column hosts all of them as inline buttons.

Each button is a saved prompt

When you create a Quick Step you give it a name, an optional condition, and a prompt. That is the whole thing. "Summarize this file" as the prompt becomes a button labeled Summarize. Click it, and the AI runs the same prompt the author of the column wrote.

A Quick Step is a saved prompt with a button on top. That is also the cheapest way to standardize how a team interacts with AI.

This matters more than it sounds. When everyone on the team uses the same Summarize button instead of typing their own prompt, you get consistent outputs across files. Prompt variance disappears.

"Each click sends a generic AI request." Each click sends your prompt — the exact one the column author saved.

Beyond AI — workflow actions too

Quick Steps are not exclusively AI buttons. The same column type can host draft-email, start-Teams-chat, and execute-flow actions — the standard workflow primitives SharePoint already shipped. The real power, though, comes from chaining those with AI in SharePoint.

Quick Steps unify workflow-style and AI-style actions into a single button row on every item.

The mental model: a Quick Step is "the most common thing you'd want to do with this file." Sometimes that is run an AI skill. Sometimes that is email the owner or start a chat. Either fits inside the same column.

"Quick Steps replace Power Automate." They do not. Power Automate still owns multi-step orchestration. Quick Steps are for the single-click action you reach for over and over.
