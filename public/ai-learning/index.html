How this index works

Conventions

  • One folder per collection — every collection lives in Content/<Name_YYYYMMDD>/ and keeps its own index.html as a collection home.
  • This page lists everything — each individual guide, site, quiz, and flashcard page under Content/ is linked directly here, grouped by collection.
  • Self-contained — each collection bundles its own pages and styles. The folders don't depend on each other.
  • Adding pages — drop the new HTML into its collection folder, then copy a .site card in the matching .group and point href at it. For a brand-new collection, copy a whole section.group block and update the stats above.
  • Color lanes — cat-agent (slate), cat-applied (amber), cat-advanced (vermillion). Reuse, or add a new .cat-* rule with a fresh --c.
