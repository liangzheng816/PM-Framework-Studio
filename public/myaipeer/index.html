What MyAIPeer can do

One zero-dependency Node CLI (node MyAIPeer/cli.mjs) covers the whole loop: build a 27-type PM ontology from your work, recall connected atoms from it, and run four PM agents that synthesize on top of it. Every agent saves a Markdown artifact to ./Output/.

Build memory build-memory

Harvest → Extract → Upsert → Index your own M365 signals into durable local Markdown — with a preserved human ## Notes area that's safe to hand-edit.

The build pipeline

The core of build-memory is a four-stage pipeline. Each stage persists on its own, so a late failure (e.g. an extraction timeout on a large window) never loses the work earlier stages already wrote.

01 · HARVEST

Harvest

Pull WorkIQ signals plus file / mail / calendar activity into the local .signals cache.

02 · EXTRACT

Extract

One local LLM pass turns raw signals into typed entities, prioritizing ingested src-* imports.

03 · UPSERT

Upsert

Deterministic, idempotent merge into Markdown entity files — array union, document dedupe, Graph metadata wins.

04 · INDEX

Index

Rebuild per-collection INDEX.md, the global MEMORY.md hot cache, and edges/INDEX.md.

Grounded by design. Every ontology entity carries sources, confidence, sensitivity, and as_of. When a critical fact is missing, MyAIPeer emits [TBD: …] rather than inventing a name, date, or URL.

Five PM agents

Packaged for Claude Code / VS Code Copilot as context-isolated sub-agents that wrap the matching CLI command, then read back the saved Output/ artifact — keeping large generated drafts out of your main thread.

Brief peer-brief

A concise Morning Brief grounded in memory + recent signals: TL;DR, decisions, risks, customer signals, action items.

Prep peer-prep

1:1 (person) or meeting prep with context summaries, goals, open loops, and talking points.

Write peer-write

Context-grounded drafting for PRDs, MC posts, newsletters, FAQs, blogs, and memos — with [TBD] markers for missing facts.

Review peer-review

Multi-persona review over a draft file with prioritized gaps, risks, and revisions.

Story peer-storytelling

Executive summary, press release, strategic narrative, or customer / partner story — grounded in memory, as Markdown or a self-contained HTML deck. Asks audience, density, and style; ships a 14-theme deck kit.

Setup

Minimal — no npm install, no virtualenv, no API keys, no .env. One required toolchain, one optional precision upgrade.

RequirementWhyNotes
Node.js ≥ 18MyAIPeer runtimeZero npm dependencies
GitHub Copilot CLI + WorkIQ MCPSignal harvesting + local LLM extract / synthesisRequired. node MyAIPeer/cli.mjs doctor verifies
Microsoft Graph (WAM broker)Exact files / mail / calendar / people precisionOptional, Windows — graph-onboard. Degrades to WorkIQ-only without it
Quickstart
# From the workspace root (C:\Code\MyPeerPM)
node MyAIPeer/cli.mjs doctor
node MyAIPeer/cli.mjs sources
node MyAIPeer/cli.mjs graph-onboard            # optional (Windows): exact files/mail/calendar/people
node MyAIPeer/cli.mjs build-memory --days 14
node MyAIPeer/cli.mjs brief --days 1

For producer-driven ingestion:

node MyAIPeer/cli.mjs ingest <signals.json> --source <name>
node MyAIPeer/cli.mjs build-memory --from-cache
