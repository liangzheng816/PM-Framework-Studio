How this index works

Conventions

  • One file per issue — source dashboards live (pristine) in RAW/ named ai-intel-dashboard-YYYYMMDD-HHMMSS.html. The timestamp sorts freshness.
  • This page is generated — run npm run build:ai-weekly after adding a dashboard. It rebuilds the cards and stats, and writes a site-themed copy of the dashboard into pages/.
  • Self-contained — each dashboard bundles its own data, filters, and sort. The index only links to the themed pages/ copies.
  • Theming is automatic — the generator copies each RAW/ dashboard into pages/ as ai-weekly-digest-YYYYMMDD-HHMMSS.html with the editorial palette and a back-to-index strip applied. RAW/ stays untouched.
