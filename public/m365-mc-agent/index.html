What the agent can do

Draft

Generate corpus-grounded MC post drafts in the right structure for the active vertical. Missing facts get [TBD: …], never fabricated.

Review

Final-reviewer pass on your draft — findings ordered Must Fix → Should Fix → Polish, calibrated to the active vertical's terminology.

Critique

Adversarial pre-publication gate — 7-dimension scorecard, named failure modes, ✅/⚠️/❌ verdict. Can speak as 5 stock personas or a named colleague.

Publish

Hand off the polished draft to the Change Communications Hub wizard, or publish the same content as a SharePoint News article for internal comms.

Eight workflows, one chat prompt away
1

Review an MC post draft

Paste your draft or point at a .docx — the agent runs the structural compliance check against the active vertical's rubric and surfaces gaps in three buckets.

2

Critique (adversarial)

Toughest possible read before publish. Scorecard, audience-modeled gap questions, logical-consistency check, top-3 priority fixes — backed by corpus-grounded facet-completeness gaps. Optional persona weighting.

3

Draft a new MC post

Give it the PM spec; it picks the corpus structure, fills the vertical's terminology, and flags every missing fact with [TBD] markers.

4

Find similar prior posts

TF-IDF search across one vertical or all of them — returns MC IDs, titles, snippets, matched terms, and links. Now facet-aware: filter by change-type / lifecycle / cloud ring and get a facet profile of the hits. Cross-vertical hits are pattern evidence, not authority.

5

Internal signal enrichment

Opt-in mid-draft: pulls authoritative facts from your SharePoint + meeting decisions via WorkIQ. Informal chat is cited, never inlined as published prose.

6

Export as Word

Markdown → .docx for emailing the draft to a PM lead or comms partner. Not the publish path — review-share only.

7

Publish to CCH

Drives the Change Communications Hub wizard via Playwright MCP. Requires a Roadmap ID; if you don't have one, the upstream skill creates that first.

8

Publish as SharePoint News

Same content, internal-facing employee announcement. Complementary to CCH, not a replacement — for most launches you'll do both.

Vertical-isolated by default

The agent confirms which service you're working on before any Review or Draft, and never silently mixes terminology across services. Cross-vertical lookup is opt-in.

Grounded in a per-vertical ontology

Each vertical's corpus is distilled into its own tailored ontology — canonical service names; change-type / lifecycle / cloud-ring / impact facets; and the baseline rate at which real posts include each section. The verticals are never mixed: Teams norms never leak into SharePoint. Review, Draft, and Critique use it to flag exactly what a draft is missing — with the corpus percentage to back it.

Five stock critique personas

Each persona reweights the scorecard and voices gap questions in their concerns. Add your own by dropping a new file into references/critique-personas/.

Compliance

Compliance Officer

Hardest pushback on data-handling statements, retention language, default-state opt-outs.

CCH

CCH Reviewer

Rollout precision, environment vs. clouds match, publish-date sanity, Roadmap ID present.

Engineering

Eng Manager

Telemetry story, rollback path, compressed TR→GA windows, dependency risk.

Product

Senior PM

Customer-problem narrative, benefit clarity, framing — capability-first writing gets flagged.

Support

Support Lead

Help-desk readiness, default-state clarity, concrete user-visible behavior beats abstractions.
